# ADR 0016：块与符号复用、AI 结果质量门禁、反馈闭环与技能导入导出

- 状态：已采纳
- 日期：2026-10-22
- 相关：ADR 0004（AI 工具调用）、ADR 0005（预览与单步撤销）、ADR 0010（Agent 循环）、ADR 0013（技能与设计上下文）、ADR 0014（计划模式与检查面板）、ADR 0015（设计约定与多方案）

## 背景

P2 让 AI 具备项目级的连续性（约定、版本记忆、多方案、参考图），但仍存在四类缺口：

1. **不会复用**：块系统是项目里已经沉淀的标准件与符号库，AI 却只会从零重画，
   既慢又与项目既有标准不一致。
2. **不会把关**：AI 生成的变更是否引入退化几何、重复图元或缺失标注，
   只能靠用户自己在「检查」面板里事后发现。
3. **不会被纠正**：没有从用户处收集「这个回答有没有用」的信号，
   技能是否真的好用无从判断；轮次回执只统计了应用 / 放弃，没有质量评价。
4. **不能迁移**：技能只能在本机建，团队之间无法交换已调好的提示词与流程。

## 决策

### 1. 块复用走「块目录 + 展开为图元」，不新增第二条写入路径

- 每轮请求前，前端拉取 `/api/blocks/tree`，用 `lib/blockCatalog.ts` 压成扁平目录
  （去重、分类下钻深度上限 8、条目上限 500），随草稿一起进入 Agent 循环。
- 模型先用只读工具 `list_blocks` 检索块库，再用 `insert_block`（`blockId` / `x` / `y` /
  `scale` / `rotation`）插入；服务端对参数做边界校验。
- 插入在草稿上把块展开为图元：平移、缩放、旋转复用 `moveElements` / `scaleElements` /
  `rotateElements`，因此结果与普通绘制走同一条预览与单步撤销管线。
- 块目录在进入循环前加载，纯函数循环内部不做 IO；目录缺失时 `insert_block` 直接失败，
  不产生半截图元。

### 2. 质量门禁只针对「本轮新增」的问题

- 预览弹窗在展示变更前跑一遍与「检查」面板同源的确定性规则（`lib/designReview.ts`），
  对比改动前后的检查结果，取差集作为本轮引入的问题。
- 既有历史问题不追责：图纸本来就脏时，不应阻止用户接受 AI 的其他改动。
- 只有 **error 级**问题阻断应用，且必须显式勾选「确认接受检查错误」；
  warning / info 只做提示，避免门禁变成噪音源。
- 同一份规则、同一套严重度，检查面板与预览门禁不会出现两套口径。

### 3. 反馈闭环复用既有消息 metadata，不新增表

- 每条 AI 回答提供「有帮助 / 没帮助」按钮，「没帮助」可附原因。
- 反馈写回该轮助手消息的 `ChatMessage.metadata`（`feedback` + `feedbackSkillCodes`），
  不引入新表与新迁移；历史回放时从 metadata 还原反馈状态。
- `GET /api/skills/stats` 聚合反馈，按技能 code 统计 up / down 与有用率；
  没有反馈的消息不计入分母，避免把「未评价」当成差评。
- 反馈写入同样受项目归属校验与参数长度限制，指标为 `ai.feedback_up` / `ai.feedback_down`。

### 4. 技能导入导出用带版本号的 JSON + 客户端严格校验

- 导出格式为 `aiignite-skill` v1：包含 code、名称、描述、分类、提示词模板、工具白名单、
  关键词、步骤、检查、示例、上下文信号、反关键词与优先级。
- 导入在浏览器侧用 `lib/skillTransfer.ts` 完整校验：未知工具、未知上下文信号、
  超长提示词、越界数组长度一律拒绝并给出原因；校验通过后先出预览再落库。
- 目标代码已被占用时自动追加副本后缀（`code-copy`、`code-copy2`…），导入前在预览里
  显示最终代码，不做静默改名。
- 导入统一走既有 `POST /api/skills`，服务端再做一次同样的边界校验，客户端校验不是唯一防线。

## 后果

- 块复用让 AI 的产出与项目既有标准一致，但块目录会占用每轮请求的一部分上下文；
  目录有条目上限与检索裁剪，且只在块库非空时才有实际收益。
- 质量门禁可能让用户多一次勾选，但这正是「AI 敢不敢直接落图」的取舍点；
  门禁只看差集，不会因为图纸本来就脏而无法推进。
- 反馈写在 metadata 上，聚合时要扫最近若干天的助手消息；
  统计窗口有上限（默认 30 天，最多 365 天，单次最多扫描 5000 条）。
- 技能导入导出让技能可以跨环境传递，但导入文件仍受服务端字段限制约束；
  格式带版本号，未来字段演进以新增版本号的方式兼容。
- 测试覆盖：`tests/blockCatalog.test.ts`、`tests/previewReview.test.ts`、
  `tests/skillTransfer.test.ts`、`tests/aiChatHistory.test.ts`（反馈还原）、
  `backend/tests/chatSessions.test.ts`（反馈路由）、`backend/tests/skills.test.ts`（有用率统计）、
  `tests/e2e/aiChat.spec.ts`（块插入、门禁、反馈）与 `tests/e2e/skills.spec.ts`（导入导出）。
