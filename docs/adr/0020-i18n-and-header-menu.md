# ADR 0020：中英双语与顶栏菜单收口

- 状态：已采纳
- 日期：2026-10-23
- 相关：ADR 0019（AI 浮窗）、ADR 0018（工具契约）

## 背景

界面文案长期中英混杂：部分面板整块英文、部分整块中文，首次打开时用户无法预期语言；同时顶部同时摆放撤销 / 重做、保存、导入、参考图、导出、打印、版本、AI、语言、主题等十余个按钮，文件类低频动作与高频动作混在一起，顶栏在窄屏下拥挤。

## 决策

### D1｜默认中文，英文可选

- 未保存过选择的用户一律使用 `zh`，不跟随浏览器语言，避免国内用户首次打开看到英文。
- 页头提供语言按钮，在中 / EN 之间切换；选择写入 `localStorage`（键 `aiignitecad.locale`），刷新后保持。
- 文案集中到 `lib/i18n.tsx` 的扁平字典：
  - `TranslationKey` 由 `zh` 字典的键推导，`en` 必须实现同一组键，漏键在编译期暴露；
  - 支持 `{placeholder}` 插值；
  - `lib/` 内需要复用的确定性文案（图纸检查问题描述、修复提示词）接收 `ReviewLocale` 参数，不把 React 依赖带进纯函数层；
  - 组件统一通过 `useI18n()` 取 `t`，不直接读字典。
- 覆盖范围：登录 / 注册、欢迎页、顶栏、工具条、页脚、属性 / 检查 / 约定 / 设置 / 用户资料、形状与填充 / 阵列 / 快速选择 / 参考图转 CAD / 打印 / 版本弹窗、通知，以及 AI 对话与变更预览主流程。AI 助手管理、技能编辑与模型配置等深层面板暂保留中文，后续按同一字典补齐。

### D2｜顶栏按「高频动作 + 文件菜单」分组

- 保留在顶栏：撤销 / 重做、保存、AI 助手、语言、主题、导出。
- 新增「文件」下拉菜单：导入 DXF / DWG、参考图转 CAD、导出 DXF、打印 / 绘图、版本历史、保存版本。
- 左侧工具条、右侧检查器、底部命令行的三区布局不变；文件菜单只重组入口，不改变任何业务能力。
- 菜单项使用 `role="menuitem"`，菜单容器使用 `role="menu"`，点击外部或选中后关闭；E2E 通过 `data-action="file-menu"` 定位。

## 后果

- 默认体验统一为中文；英文模式覆盖主编辑流程，仍有少量深层配置面板待补齐。
- 新增文案必须同时补齐中英文，字典一致性由 `tests/i18n.test.ts` 兜底。
- 顶栏在窄屏下少了一排文件按钮；打印、版本、参考图等入口从「平铺」变为「文件菜单 → 子项」，E2E 与文档同步更新。
