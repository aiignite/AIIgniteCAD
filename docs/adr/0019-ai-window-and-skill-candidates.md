# ADR 0019：AI 助手浮窗 / 抽屉与技能候选编排

- 状态：已采纳
- 日期：2026-10-23
- 相关：ADR 0004（AI 工具调用）、ADR 0010（Agent 循环）、ADR 0013（技能剧本与设计上下文）、ADR 0018（工具契约）

## 背景

AI 对话原先挂在右侧栏的 `CHAT` 模式，助手 / 技能 / 模型各自是并列的侧栏页面：

- 每次「问 AI」都要切走右侧面板，画布与对话不能并排操作；
- 技能只有手动 pin 与回合结束后的激活 chip，用户输入时看不到本轮可能命中的技能；
- 路由只使用当前消息关键词，短消息（“继续 / 好的”）会让技能整体掉线，跨轮话题也没有衰减信号；
- 助手 / 技能 / 模型页面与对话割裂，配置后无法立即回到同一轮对话。

AIIgnitePLM 的全局 AI 助手采用「顶部入口 + 非模态浮窗 + 可切抽屉 + 输入期技能候选」，
本 ADR 将其交互与路由规则收敛到 CAD 场景。

## 决策

### D1｜顶部入口与非模态浮窗

- Header 增加 AI 图标，点击打开 `AIAssistantWindow`，再点或 `Esc` 关闭。
- 浮窗默认贴在 Header 下方右侧，可拖动、八向缩放；位置与尺寸写入 `localStorage`。
- 标题栏按钮可切换为右侧全高抽屉；抽屉只拖左边缘改宽度，不把宽度写回浮窗记忆。
- 视口窄于 640px 时铺满 Header 以下，禁用拖动与缩放。
- 浮窗为非模态（`aria-modal="false"`），画布保持可操作；预览等模态仍以更高层级覆盖。

### D2｜配置按钮改为内部抽屉

助手管理、技能管理、模型设置、会话历史从右侧栏迁入 AI 浮窗内部抽屉：

- 抽屉只覆盖对话内容区，不关闭对话，也不丢输入草稿；
- 助手 / 技能 / 模型共用 `useAIRegistry` 快照，保存后立即刷新；
- 右侧栏不再承担 AI 配置，`SidePanelMode` 仅保留检查 / 约定 / 文件 / 设置 / 用户信息。

### D3｜输入期技能候选（与激活共用一套打分）

新增 `POST /api/skills/resolve`，与回合内 `activateSkills` 共用 `skillRouter`：

1. 后端返回正分候选（最多 8 条），前端过滤低于激活线（12 分）的项，最多展示 3 条；
2. 候选条显示分数、路由原因，可逐项移除 / 恢复；
3. 用户保留的候选随 `recommendedSkillCodes` 下发，加 25 分参与路由，但仍需过阈值——
   固定技能（`pinnedSkillCodes`，100 分）才是绕过规则的特例；
4. 固定技能始终出现在候选条并置顶，避免用户不知道它仍会注入。

### D4｜跨轮路由规则

参考 PLM 的会话连续性规则，新增两条：

- **历史关键词衰减**：当前消息未命中时回看最近 3 条用户消息，按 `0.5^depth` 计分（深度 1 = 最近一条）；
- **短消息沿用**：消息长度 < 8 且当前消息无关键词命中时，沿用上一轮激活技能（`continuity_carryover`）；
  固定技能存在时跳过沿用。

设计上下文（选择集 / 图层 / 块 / 提交次数 / 标注）与选择类型仍只放大已有意图，不能单独越过阈值。

## 后果

- 对话与画布可以同时使用，配置 AI 不再打断对话；
- 候选条让用户在发送前知道哪些技能会注入，并可纠正误匹配；
- 跨轮追问不再因为“继续”丢失技能，旧话题只保留低权重信号；
- 新增 `/skills/resolve` 请求在输入时防抖触发，浮窗关闭或消息过短时不请求；
- 浮窗隐藏时组件保持挂载，关闭再打开不丢会话视图；对应代价是 AI 面板状态常驻内存。
