# ADR 0009：图框 / 打印使用毫米坐标系与矢量输出

- **状态**：Accepted
- **日期**：2026-10-21
- **决策者**：前端与制图团队

## 背景

编辑器只有模型空间与屏幕视口，没有纸张、比例和标题栏概念，用户无法输出带图框的工程图。直接截图会丢失矢量清晰度，也无法保证 1:100 等比例在纸面上的物理尺寸正确。

## 决策

1. **两套坐标显式分离**：图纸用毫米，模型用世界单位；比例尺 `scale` 定义为“每世界单位对应的毫米数”，1:N 时 `scale = 1/N`。布局计算集中在 `lib/plot.ts`，不依赖 React/DOM。
2. **所见即所得**：屏幕预览与打印使用同一个 `components/PlotSheet.tsx`。外层 SVG 的 `viewBox` 为纸张毫米尺寸，绘图区是嵌套 SVG，其 `viewBox` 为按比例换算后的世界坐标。
3. **图元渲染复用**：`CADElementRenderer` 增加可选的 `overrides`（线宽、`non-scaling-stroke`、单色），打印时关闭 `non-scaling-stroke` 并把 0.25mm 线宽换算成世界单位；屏幕渲染保持原有行为。
4. **打印通道**：`PlotModal` 通过 portal 在 `body` 下渲染隐藏的打印根节点，并用动态 `@page { size: …mm …mm; margin: 0 }` 指定纸张。打印时隐藏 `#root`，只保留图框。PDF 由浏览器打印对话框的“另存为 PDF”生成，不引入 PDF 库。
5. **标题栏**：可选，固定在右下角，包含图名、图号、比例、图幅、日期与作者；图幅与比例来自同一布局结果，避免显示与实际输出不一致。

## 理由

- 毫米 + 世界单位的显式换算可以保证 1:N 比例和 0.25mm 线宽在纸上可验证。
- 预览与打印共用组件，避免“预览好看、打印错位”的常见问题。
- 复用现有图元渲染器，新增图元类型只需扩展一处。
- 浏览器打印即可产出矢量 PDF，零新增依赖，符合当前离线优先与轻量部署约束。

## 后果

- 固定比例下内容可能超出绘图区，UI 必须提示裁切；当前不做自动分页或视口裁剪。
- 图框与标题栏是内置样式，暂不支持用户自定义模板或属性块。
- 打印依赖浏览器对 `@page` 与 SVG 毫米尺寸的实现；Chrome / Edge 已覆盖，其他浏览器需回归。
- 图元颜色若为浅色，单色模式会统一为黑色；关闭单色时主题默认色仍映射为黑色以保证白纸可见。
- 移动端打印对话框能力有限，打印功能面向桌面浏览器。
